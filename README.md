# Athena 추천 작업 테스트 마켓플레이스

Athena Code 의 "추천 작업"에 플러그인의 항목이 덧붙는지 확인하기 위한 테스트용 마켓플레이스입니다.
플러그인의 항목은 기본 제공 항목을 바꾸지 않고 그 뒤에 붙습니다.

- 저장소: https://github.com/hrkimuracle-gif/athena-preset-prompts (임시. 이후 사내 git 으로 이전 예정)
- 마켓플레이스 이름: `athena-preset-prompts`

| 플러그인 | 설치 ID | 항목 수 | 확인하려는 것 |
| --- | --- | --- | --- |
| 우리 팀 추천 작업 | `team-prompts@athena-preset-prompts` | 5 | 카테고리, 모드 전환, 설치 필요 표시, 분류 없는 항목 |
| 고객사 A 추천 작업 | `customer-prompts@athena-preset-prompts` | 2 | 플러그인이 둘일 때 따로 묶이는지 |

추천 작업을 플러그인으로 받는 기능이 들어간 Athena Code 빌드에서만 동작합니다.
그 이전 빌드에서는 플러그인이 목록에 보이고 설치도 되지만, 추천 작업은 바뀌지 않습니다.

## 설치

1. Athena Code 설정 > 플러그인에서 마켓플레이스 소스를 추가합니다.
   - 주소: `https://github.com/hrkimuracle-gif/athena-preset-prompts.git`
   - 인증: 없음 (공개 저장소)
2. 목록에서 "우리 팀 추천 작업"을 설치하고 켭니다. 필요하면 "고객사 A 추천 작업"도 켭니다.
3. 새 채팅을 열어 시작 화면을 봅니다.

## 확인할 것

### 설정 > 추천 작업

- [ ] 기본 제공 항목 아래에 "플러그인: 우리 팀 추천 작업" 구역이 생기고 항목 5개가 보인다.
- [ ] 두 번째 플러그인을 켜면 "플러그인: 고객사 A 추천 작업" 구역이 따로 생긴다.
- [ ] "사내 보안 점검 실행"에 경고 아이콘이 붙고, 마우스를 올리면 "설치 필요: acme-security-audit"이 나온다. 이 항목은 고정할 수 없다.
- [ ] 항목을 펼치면 프롬프트 내용이 보인다.
- [ ] 플러그인 항목을 고정하면 저장 버튼을 누르지 않아도 시작 화면의 고정 탭에 나온다.

### 채팅 시작 화면

- [ ] 추천 탭에 플러그인 항목이 섞여 나오고, 제목 옆에 플러그인 이름이 붙는다. 안 보이면 새로 고침을 누른다.
- [ ] "사내 보안 점검 실행"은 추천에 나오지 않는다.
- [ ] 항목을 누르면 바로 보내지 않고 프롬프트가 입력창에 들어간다.
- [ ] "API 흐름 질문하기"를 누르면 모드가 질문(Ask)으로 바뀐다.

### 끄고 켜기

- [ ] 플러그인을 끄면 그 항목이 설정과 시작 화면에서 사라진다.
- [ ] 고정해 둔 플러그인 항목은 플러그인을 끄면 고정 탭에서 빠지고, 다시 켜면 돌아온다.

## 저장소 구성

```
marketplace.json                       마켓플레이스 정의
packages/<플러그인 이름>/
  .athena-plugin/plugin.json           플러그인 정의 (이름, 버전, 설명)
  preset-prompts.json                  추천 작업 목록
```

`preset-prompts.json` 은 플러그인 폴더 바로 아래에 이 이름으로 두면 따로 선언하지 않아도 인식됩니다.

## 추천 작업 파일 형식

```json
{
	"prompts": [
		{
			"id": "pr-description",
			"title": "PR 설명 초안 쓰기",
			"description": "지금 브랜치의 변경을 읽고 PR 설명 초안을 만들어요.",
			"prompt": "입력창에 들어갈 프롬프트 전문",
			"category": "devDocs",
			"mode": "ask",
			"requires": "스킬이나 슬래시 명령 이름"
		}
	]
}
```

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `id` | 예 | 파일 안에서 유일한 값, 64자 이하. 사용자의 고정이 이 값을 가리키므로 한번 배포한 뒤에는 바꾸지 않습니다. |
| `title` | 예 | 60자 이하 |
| `description` | 아니오 | 120자 이하 |
| `prompt` | 예 | 8000자 이하. 줄바꿈과 탭을 쓸 수 있습니다. |
| `category` | 아니오 | `devStart`, `devReview`, `devTest`, `devDocs` 중 하나. 없으면 분류 없음입니다. |
| `mode` | 아니오 | 누를 때 바꿔 둘 모드의 slug. 없는 모드면 바꾸지 않습니다. |
| `requires` | 아니오 | 필요한 스킬이나 슬래시 명령의 이름. 설치되어 있지 않으면 시작 화면에 나오지 않습니다. |

제한:

- 파일 하나에 항목 30개, 512KB 까지입니다.
- 제목, 설명, 프롬프트에 보이지 않는 문자나 제어 문자를 쓸 수 없습니다. 프롬프트에 빈 줄이 3줄 이상 이어질 수 없습니다.
- 하나라도 맞지 않으면 그 플러그인의 항목 전체를 쓰지 않습니다.

## 항목을 고친 뒤

항목을 고치면 `.athena-plugin/plugin.json` 의 `version` 을 올려서 올립니다. Athena Code 에서 마켓플레이스를 새로 고친 뒤 플러그인을 업데이트하면 반영됩니다.
