# Athena 추천 작업 마켓플레이스

Athena Code 채팅 시작 화면의 "추천 작업" 목록을 플러그인 형태로 배포하는 마켓플레이스 저장소입니다.
고객사나 팀마다 다른 추천 작업을 내려보낼 때 이 저장소를 본떠 만듭니다.

- 저장소: https://github.com/hrkimuracle-gif/athena-preset-prompts (임시. 이후 사내 git 으로 이전 예정)
- 마켓플레이스 이름: `athena-preset-prompts`
- 플러그인: `sample-preset-prompts` (설치 ID `sample-preset-prompts@athena-preset-prompts`)

추천 작업을 플러그인으로 받는 기능이 들어간 Athena Code 빌드에서만 동작합니다.
그 이전 빌드에서는 플러그인이 목록에 보이고 설치도 되지만, 추천 작업 목록은 바뀌지 않습니다.

## 사용 방법

1. Athena Code 플러그인 설정에서 마켓플레이스 소스를 추가합니다.
   - 주소: `https://github.com/hrkimuracle-gif/athena-preset-prompts.git`
   - 인증: 없음 (공개 저장소)
2. 마켓플레이스 목록에서 "추천 작업 예시" 를 설치하고 켭니다.
3. 채팅 시작 화면의 추천 작업 목록이 이 플러그인의 목록으로 바뀝니다.

## 동작

- 켜면 저장된 추천 작업 목록을 이 플러그인의 목록으로 통째로 교체합니다. 직접 편집한 내용도 함께 사라집니다.
- 교체된 뒤에는 설정 > 추천 작업에서 자유롭게 고칠 수 있고, 같은 버전인 동안에는 다시 덮어쓰지 않습니다.
- 플러그인 버전이 올라가면 새 버전의 목록으로 다시 교체합니다.
- 플러그인을 끄거나 지우면 Athena Code 에 내장된 기본 목록으로 돌아갑니다.
- 추천 작업을 제공하는 플러그인이 여러 개 켜져 있으면 가장 나중에 설치한 플러그인의 목록을 씁니다.

## 저장소 구성

```
marketplace.json                          마켓플레이스 정의
packages/sample-preset-prompts/
  .athena-plugin/plugin.json              플러그인 정의 (이름, 버전, 설명)
  preset-prompts.json                     추천 작업 목록
```

`preset-prompts.json` 은 플러그인 폴더 바로 아래에 이 이름으로 두면 따로 선언하지 않아도 인식됩니다.

## 추천 작업 파일 형식

```json
{
	"schemaVersion": 1,
	"prompts": [
		{
			"id": "sample-explain-file",
			"title": "열린 파일 설명",
			"description": "지금 열려 있는 파일이 하는 일을 설명합니다",
			"prompt": "지금 편집기에 열려 있는 파일을 설명해 주세요.",
			"mode": "ask"
		}
	]
}
```

| 항목          | 필수 | 제한                    | 설명                                                           |
| ------------- | ---- | ----------------------- | -------------------------------------------------------------- |
| `id`          | 예   | 64자, 목록 안에서 유일  | 항목을 구분하는 값                                             |
| `title`       | 예   | 60자                    | 목록에 보이는 제목                                             |
| `description` |      | 120자                   | 제목 아래 한 줄 설명                                           |
| `prompt`      | 예   | 8000자                  | 항목을 누르면 그대로 실행되는 프롬프트                         |
| `mode`        |      |                         | 실행 전에 바꿀 모드 이름. 그 모드가 없으면 현재 모드로 실행    |

- 항목은 최대 30개, 파일 크기는 최대 512 KB 입니다.
- 형식이 맞지 않으면 목록 전체를 쓰지 않고, 추천 작업 목록은 바뀌지 않습니다.
- 목록에는 파일에 적은 순서대로 나오고, 채팅 시작 화면에는 처음 4개가 먼저 보입니다.

## 목록 갱신

1. `preset-prompts.json` 을 고칩니다.
2. `.athena-plugin/plugin.json` 의 `version` 을 올립니다. 버전을 올리지 않으면 이미 받은 사용자에게는 반영되지 않습니다.
3. 커밋하고 푸시하면 마켓플레이스에서 새 버전으로 보입니다.

## 고객사용으로 만들 때

1. 이 저장소를 복사해 `marketplace.json` 의 `name` 과 플러그인 폴더 이름, `plugin.json` 의 `name` 을 바꿉니다.
2. `preset-prompts.json` 을 고객사의 추천 작업으로 채웁니다.
3. 고객사 포탈의 마켓플레이스 저장소로 등록합니다.
